# Solicitud de tickets (script sencillo)

Script en Python que simula la atención inicial de soporte N1.

## Qué hace
- Pregunta el nombre y el área del usuario.
- Pregunta si necesita ayuda de soporte.
- Si responde "si", pide la extensión y genera un resumen del ticket.

## Cómo ejecutarlo
python script-sencillosolicitud-tickets.py

## Conceptos que practiqué
- input y print
- if / else
- f-strings
